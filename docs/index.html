    Supported in this build

    • STL (binary + ASCII)
    • OBJ (+ MTL if supplied)
    • glTF / GLB (incl. Draco)
    • PLY
    • AMF
    • STEP (AP203 / 214 / 242)
    • IGES
    • BREP

    Proprietary formats (JT, SolidWorks, CATIA, NX, Inventor, Creo, DWG, Parasolid, ACIS, FBX) are not supported — export STEP from your CAD system and open that instead. STEP, IGES and BREP are parsed by OCCT (7.6.1) in the browser; the WASM (~8 MB) downloads only when a B-rep file is opened.
